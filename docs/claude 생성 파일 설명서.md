> 기준일: 2026-09-25

## 0. 세 줄 요약

1. 사이트의 모든 것은 **`D:\work\iLINE-edu-support`** 폴더 하나에 들어 있습니다.
2. Claude 가 쓰는 `lib/config/venues.ts` 같은 이름은 **그 폴더 안의 위치**입니다.

## 1. 폴더 네 개만 알면 됩니다

```
D:\work\iLINE-edu-support\
├── docs\          ← 읽는 문서 (매뉴얼·할 일·결정 기록)
├── app\           ← 화면. 폴더 이름이 곧 인터넷 주소
├── components\    ← 화면 안의 부품 (여러 화면이 나눠 쓰는 조각)
└── lib\           ← 설정값과 계산 규칙 (화면에 안 보이는 속)
```

| 폴더 | 무엇이 들었나 | 사람 말로 |
|---|---|---|
| **`docs\`** | 문서만 | **여기는 메모장으로 열어도 됩니다.** 코드가 아닙니다 |
| **`app\`** | 화면 하나 = 폴더 하나 | `app\reserve` = `aiedu.iline.or.kr/reserve` (시설 예약 화면) |
| **`components\`** | 화면 부품 | 카드·버튼·신청서 같은 조각. 여러 화면이 같은 부품을 씁니다 |
| **`lib\`** | 값과 규칙 | 공부실 목록, 마감 계산, 데이터베이스 연결 같은 것 |

이 밖에 `public\`(이미지 같은 붙박이 파일), `scripts\`(가끔 손으로 돌리는 도구)가 있지만
평소에 볼 일은 없습니다.

## 2. `app\` 은 주소와 같습니다

이 사이트는 **폴더 이름이 그대로 주소가 되는 방식**(Next.js App Router)으로 만들어졌습니다.
그래서 Claude 가 `app\...` 경로를 말하면 **주소를 말한 것**과 같습니다.

| 폴더 | 주소 | 화면 |
|---|---|---|
| `app\page.tsx` | `/` | 홈 |
| `app\apply\` | `/apply` | 프로그램 신청 목록 |
| `app\apply\[id]\` | `/apply/2026-ai-edu` | 공고 상세 (대괄호 `[id]` = "여기는 프로그램마다 달라짐") |
| `app\reserve\` | `/reserve` | 시설 예약 |
| `app\mypage\` | `/mypage` | 마이페이지 |
| `app\staff\` | `/staff` | 관리 (담당자 전용) |
| `app\staff\reservations\add\` | `/staff/reservations/add` | 관리 → 예약 관리 → 직접 예약 추가 |
| `app\notice\faq\` | `/notice/faq` | 알림마당 → 자주 묻는 질문 |

## 3. 파일 확장자 — `.ts` 와 `.tsx` 와 `.md`

| 끝 글자 | 무엇 | 예 |
|---|---|---|
| **`.md`** | **문서.** 글만 있습니다. 메모장·워드로 열어도 됩니다 | `docs\작업지시서.md` |
| **`.tsx`** | **화면을 그리는** 파일 | `ReserveFlow.tsx` (예약 화면) |
| **`.ts`** | **값과 계산만** 있는 파일. 화면은 안 그림 | `venues.ts` (공부실 목록) |
| **`.rules`** | **데이터베이스 출입 규칙** | `firestore.rules` |
| **`.json`** | 설정값 묶음 | `package.json` |

`venues.ts` 가 `.ts` 인 이유: "공부실 목록은 **자료**일 뿐이고, 그걸 보여 주는 **화면**은 따로"
라는 뜻입니다. 자료와 화면을 갈라 두면 자료 한 곳만 고쳐도 모든 화면이 같이 바뀝니다.

## 4. 코드 이름 읽는 법

Claude 가 `Venue.notice?: string` 같이 쓸 때:

| 조각 | 뜻 |
|---|---|
| `Venue` | **"공부실"이라는 자료 한 덩이.** 호실·이름·좌석 수 등이 한 묶음 |
| `.notice` | 그 묶음 안의 **칸 하나**의 이름 |
| `?` | **"비워 둬도 된다"** 는 표시 |
| `: string` | 그 칸에 **글자**가 들어간다는 뜻 (`number` 면 숫자) |

합치면 — *"공부실 자료에 `notice`(주의사항)라는 **글자 칸**을 하나 뒀고, **비워 둬도 된다**"*.
실제로 2316 에만 값이 있고 나머지 세 곳은 비어 있어서, 2316 을 골랐을 때만 안내가 뜹니다.

자주 나오는 것 몇 개 더:

| 이름 | 뜻 |
|---|---|
| `Program` | 공고 한 건 (이름·기간·대상 등) |
| `Application` | 신청서 한 건 |
| `Notice` | 공지사항 한 건 |
| `Venue` | 공부실 한 곳 |
| `ReservationSettings` | 예약 운영 설정 (마감 요일·휴관일 등) |

## 5. `D-숫자` 는 무엇인가

**결정 하나에 붙인 일련번호**입니다. `D-94` = 아흔네 번째 결정.
전부 `docs\작업지시서.md` 에 표로 정리돼 있고, 무엇을 왜 그렇게 정했는지가 적혀 있습니다.
`D-93′`(작은 따옴표)는 D-93 을 나중에 보강한 것이라는 뜻입니다.

보고서에 `(D-94)` 가 붙어 있으면 **"자세한 사정은 작업지시서에서 D-94 를 찾아보라"** 는 표시입니다.

## 6. 어디서 어떻게 여나

**문서(`.md`)** — 파일 탐색기에서 `D:\work\iLINE-edu-support\docs` 를 열고 더블클릭.
메모장으로 열립니다. 표가 깨져 보이면 VS Code 로 열면 제대로 보입니다.

**코드 파일** — 굳이 열 필요는 없지만, 보고 싶으면 VS Code 로 폴더 전체를 열고
왼쪽 나무 모양 목록에서 찾아가면 됩니다.

**이 대화 안에서** — Claude 가 쓴 파란 파일 이름은 **클릭하면 바로 열립니다.**
`파일이름:42` 처럼 뒤에 숫자가 붙어 있으면 그 파일의 42번째 줄로 갑니다.

## 7. 헷갈리기 쉬운 것

- **`/` 와 `\`** — 같습니다. 윈도우는 `\`, 인터넷·개발 도구는 `/` 를 씁니다
- **파일 이름의 대소문자** — `venues.ts` 와 `Venues.ts` 는 다른 파일로 칩니다
- **`docs\` 안의 숫자** — `00`·`01` 은 읽는 순서일 뿐, 중요도가 아닙니다
- **`Claude outputs\` 폴더** — 옛날 복사본이 쌓인 곳입니다. **기준이 아닙니다.**
  최신본은 언제나 `docs\` 안에 있습니다
