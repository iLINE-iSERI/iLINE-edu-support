# 프로그램(공고) 등록 안내서

> 교원양성지원사업 사이트에 **참여 프로그램을 올리는 방법**입니다.
> **사이트 안에서 직접** 등록하시면 됩니다. Firebase 콘솔은 이제 필요 없습니다.
> 최종 수정: 2026-09-06 (사이트 등록 화면 신설에 맞춰 전면 개정)

---

## 0. 시작하기 전에

**필요한 것**

- 담당자 권한이 부여된 계정으로 사이트에 로그인
- 인터넷 브라우저 (휴대폰에서도 됩니다)

**소요 시간** — 처음 한 번은 5분쯤, 익숙해지면 2분이면 됩니다.

> ⚠️ **Firebase 콘솔로도 등록할 수 있지만 권하지 않습니다.** 콘솔 권한은
> 컬렉션 단위로 나눌 수 없어서, 공고를 올리려고 권한을 받으면 **학생들의
> 개인정보와 신청서까지 전부 열람·삭제할 수 있게** 됩니다. 실수로 지워도
> 되돌릴 이력이 없습니다. 아래 사이트 화면을 쓰시면 그런 위험이 없습니다.
> (콘솔 방식은 §10 부록에 남겨 두었습니다)

---

## 1. 화면 열기

1. 사이트에 **담당자 계정으로 로그인**
2. 주소창에 `/staff` — 또는 마이페이지의 담당자 안내를 통해 **신청 관리** 화면으로
3. 위쪽 **[프로그램 관리 →]** 클릭

등록된 프로그램들이 목록으로 보입니다.

---

## 2. 새 프로그램 올리기 — 큰 흐름

```
[새 프로그램 등록] → 내용 채우고 저장 (이때는 비공개)
        ↓
신청 화면에서 확인
        ↓
목록에서 [공개하기] → 학생에게 보임
```

**새 공고는 항상 비공개로 저장됩니다.** 미리보기가 따로 없어서, 공개 상태로
작성하면 미완성 내용이 그대로 학생에게 보이기 때문입니다. 다 채우고 확인한
뒤에 공개하시면 됩니다.

---

## 3. 입력 항목

### 주소용 ID — **처음 한 번만, 나중에 못 바꿉니다**

이 값이 인터넷 주소에 그대로 나옵니다.

```
support.iline.or.kr/apply/2026-ai-workshop
                          └─ 주소용 ID
```

- **영문 소문자 · 숫자 · 붙임표(-)** 만 (한글·공백은 안 됩니다)
- **연도로 시작**하면 나중에 목록에서 찾기 쉽습니다

| 좋음 | 좋지 않음 |
|---|---|
| `2026-ai-workshop` | `AI 수업 설계 워크숍` (한글·공백) |
| `2026-content-dev` | `program1` (나중에 뭐가 뭔지 모름) |

> 규칙에 안 맞거나 이미 쓰는 ID면 **저장할 때 안내가 뜹니다.** 그냥 눌러보셔도
> 됩니다 — 잘못된 채로 저장되지 않습니다.
>
> **바꿔야 한다면** 새로 만들고 옛것을 비공개로 내리세요. 다만 **신청자가 이미
> 있으면 그러지 마세요** — 그 신청이 옛 공고에 남습니다.

### 프로그램 이름 · 사업 연도

목록과 상세에 보이는 제목, 그리고 연도(예: `2026`)입니다. 연도는 목록 정렬에
쓰입니다.

### 참여 방식

| 값 | 화면에서 달라지는 것 |
|---|---|
| **개인 신청** | "개인 신청" 표시 |
| **단체 프로그램** | "단체 프로그램" 표시 + 안내 문구 + **팀 최대 인원** 칸이 나타남 |

> **지금은 둘 다 신청서가 같습니다.** 단체를 골라도 팀원 명단을 받는 칸은
> 나오지 않고 **안내 문구만 달라집니다.** 개인으로 접수받아 현장에서 팀을 짜는
> 방식이 더 흔해서 그렇게 두었습니다. 신청 시점에 팀원 명단이 꼭 필요한
> 프로그램이 생기면 그때 만들면 됩니다.

### 소개 (선택)

한두 문장이면 충분합니다. 목록 카드와 상세 화면에 보입니다.

### 접수 시작 · 접수 마감

달력에서 **날짜와 시각**을 고릅니다.

| 비워두면 | 결과 |
|---|---|
| 접수 시작 | 저장 즉시 **접수중** |
| 접수 마감 | **상시 접수** (계속 열림) |

> ⚠️ **시각까지 꼭 확인하세요.** `18:00` 이면 그날 저녁 6시 마감이지만,
> **`00:00` 이면 그날 시작하자마자 마감**입니다. 흔한 실수입니다.
>
> 마감이 시작보다 빠르면 저장할 때 안내가 뜹니다.

접수 기간 밖이면 학생에게 **"접수 예정"** 또는 **"접수 마감"** 으로 보이고,
신청 폼이 열리지 않습니다.

## 4. 신청서에 칸 추가하기 — 이 부분이 핵심입니다

프로그램마다 받을 것이 다른 문제를, **글칸 하나 + 첨부 하나**로 해결합니다.
**개발 없이 문구만 바꾸면** 됩니다.

| 원하는 것 | 이렇게 |
|---|---|
| 아무것도 더 안 받음 | **둘 다 비움** → "내 정보 확인 후 제출"만 |
| 지원 동기를 받고 싶음 | 자유 기재란 이름에 `지원 동기` |
| 영수증·증명서를 받고 싶음 | 첨부 안내 문구를 적음 |
| 반드시 내게 하고 싶음 | 각 칸 아래 **필수** 체크 |

**이름을 비우면 그 칸 자체가 신청서에 안 생깁니다.** 반대로 이름을 적으면
바로 나타납니다. 필수 체크는 칸이 있을 때만 나옵니다.

**첨부 안내 문구는 구체적으로 쓰세요.** 이 문장이 학생이 보는 유일한 설명입니다.

> 좋음: `재학증명서를 촬영해 첨부해 주세요. 사진 또는 PDF, 20MB 이하.`
> 나쁨: `증빙 서류`

첨부는 **사진(JPG·PNG·HEIC 등)과 PDF만**, 1개당 20MB 이하, 최대 5개까지
받습니다. 이 제한은 시스템이 자동으로 안내합니다.

### 정산에 영수증을 받을지

**[영수증을 반드시 첨부하게 하기]** 는 기본으로 켜져 있습니다.

| | 참여자가 정산에서 내는 것 |
|---|---|
| **켬** (기본) | 지급 계좌 + **영수증 1장 이상** |
| **끔** | 지급 계좌만 — 영수증은 선택 |

지출 증빙이 필요 없는 프로그램에만 끄세요. **정산 안내 문구**를 적으면 그 문장이
참여자 화면에 그대로 보입니다.

---

## 5. 저장하고 확인하기

1. **[저장]** — 목록으로 돌아옵니다. **비공개** 표시가 붙어 있습니다
2. 목록에서 **[신청 화면 보기]** 로 학생이 볼 화면을 확인
3. 확인할 것
   - 제목·소개에 오타가 없는지
   - **접수 기간**이 의도한 날짜·시각인지
   - 배지가 맞는지 (`접수중` / `접수 예정` / `접수 마감`)
   - **글칸·첨부칸이 의도대로** 나오는지
4. 맞으면 목록에서 **[공개하기]**
5. `/apply` 를 새로고침 → 목록에 나타나면 완료

---

## 6. 이미 올린 공고 고치기

목록에서 **[수정]** → 고치고 **[저장]**. 바로 반영됩니다.

### ⚠️ 접수가 시작된 뒤에 고칠 때

| 고치는 것 | 안전한가 |
|---|---|
| 오타 수정, 소개 문구 다듬기 | ✅ 안전 |
| 접수 마감을 **뒤로** 미루기 (연장) | ✅ 안전 |
| 접수 마감을 **앞으로** 당기기 | ⚠️ 준비 중이던 학생이 못 냅니다. **공지 먼저** |
| 글칸·첨부칸 **추가** | ⚠️ **이미 낸 사람은 그 항목이 없습니다.** 따로 받아야 합니다 |
| 프로그램 이름 변경 | ⚠️ 이미 낸 신청서에는 **옛 이름이 그대로** 남습니다 (일부러 그렇게 했습니다) |

---

## 7. 공고 내리기

목록에서 **[비공개로 내리기]**. 학생 화면에서 사라집니다.

**삭제 기능은 일부러 만들지 않았습니다.** 신청서가 딸린 프로그램을 지우면 그
신청 기록이 **어느 공고 것인지 알 수 없는 상태**가 됩니다.

> 접수가 끝난 공고는 **그냥 두세요.** 마감일이 지나면 **"지난 프로그램"** 칸으로
> 자동으로 내려갑니다. 지난 회차 기록으로 남기려면 **공개인 채로** 두시면 됩니다.

---

## 8. 함께 알아두실 것

### 공지사항 올리기

**[공지 관리]** 화면에서 같은 방식으로 올립니다. 모집 공고 안내처럼 계속 보여야
하는 것은 **[목록 맨 위에 고정]** 을 켜세요. 다만 여러 개를 고정하면 고정의
의미가 없어집니다.

### 신청 취소해 주기

학생이 잘못 신청했거나 취소를 요청하면, **신청 관리** 화면에서 해당 건의
**[신청 취소 처리]** 를 누르세요.

- 기록은 **"취소됨"** 으로 남습니다 (지워지지 않습니다)
- 그 학생이 **같은 프로그램에 다시 신청**할 수 있게 됩니다
- 사유 칸에 쓴 내용이 **학생에게 그대로 보입니다**

### 담당자가 쓴 문장은 곧 통지문입니다

상태를 바꿀 때 적는 사유는 **신청자 마이페이지에 그대로 표시**됩니다.
보완 요청이라면 **무엇을 어떻게 고쳐야 하는지** 적어주세요. 그게 없으면
학생은 전화로 물어보게 됩니다.

## 9. 잘 안 될 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 목록에 안 보임 | 비공개 상태 | **[공개하기]** |
| "접수 예정"인데 시작일이 지남 | 시작 **시각**이 아직 미래 | 시각까지 확인 |
| 신청 버튼이 없음 | 접수 기간 밖 | 정상 동작입니다 |
| 글칸·첨부칸이 안 나옴 | 이름·안내 문구가 비어 있음 | 그 칸을 채우세요 |
| 저장이 안 되고 안내만 뜸 | ID 형식·중복, 마감이 시작보다 빠름 | 안내 문구대로 |
| 화면 자체가 안 열림 | 담당자 권한이 없는 계정 | 관리자에게 문의 |

**그래도 안 되면** 화면을 캡처해서 문의해 주세요.

## 10. 부록 — Firebase 콘솔로 등록하기 (권하지 않음)

사이트 화면을 쓸 수 없는 예외 상황에서만 쓰세요. §0의 경고를 먼저 읽어주세요.

1. https://console.firebase.google.com → `iline-edu-support`
2. 왼쪽 **`빌드`** → **`Firestore Database`** → **`데이터`** 탭
3. ⚠️ 왼쪽 첫 칸에서 **`support_programs`** 를 클릭하고 시작
   — 다른 문서를 열어둔 채 만들면 **그 문서 안에** 만들어져 사이트에 안 보입니다.
   화면 위 경로가 **`🏠 > support_programs`** 여야 합니다
4. **`+ 문서 추가`** → 문서 ID(§3의 주소용 ID) → 필드 입력 → 저장

| 필드 이름 | 유형 | 필수 |
|---|---|:---:|
| `title` | 문자열 | ✅ |
| `year` | **숫자 / int64** (`number` 라는 항목은 없습니다) | ✅ |
| `participationType` | 문자열 — `individual` 또는 `group` | ✅ |
| `published` | 부울 | ✅ |
| `description` | 문자열 | |
| `opensAt` · `closesAt` | timestamp | |
| `maxTeamSize` | 숫자 / int64 | |
| `noteLabel` · `noteRequired` | 문자열 · 부울 | |
| `attachmentGuide` · `attachmentRequired` | 문자열 · 부울 | |

필드 이름은 **대소문자까지 정확히** 같아야 합니다. 연도를 문자열(`"2026"`)로
넣으면 정렬이 어긋납니다.
