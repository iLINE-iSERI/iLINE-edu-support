# 프로그램(공고) 등록 안내서

> 교원양성지원사업 사이트에 **참여 프로그램을 올리는 방법**입니다.
> 사이트 안에 등록 화면이 아직 없어서, 지금은 **Firebase 콘솔**이라는 관리 도구에서
> 직접 입력합니다. 화면을 하나씩 따라오시면 됩니다.
> 작성일: 2026-09-06

---

## 0. 시작하기 전에

**필요한 것**

- 인터넷 브라우저 (크롬 권장)
- 프로젝트에 초대된 구글 계정으로 로그인

**소요 시간** — 처음 한 번은 10분쯤, 익숙해지면 3분이면 됩니다.

**미리 알아두실 것**

여기서 입력한 내용이 **곧바로 사이트에 반영됩니다.** 미리보기가 따로 없습니다.
그래서 아래 순서에서는 **`published` 를 마지막에 켜도록** 안내합니다.
그렇게 하면 작성 도중의 미완성 공고가 학생들에게 보이지 않습니다.

---

## 1. 콘솔 열기

1. 브라우저에서 **https://console.firebase.google.com** 접속
2. 프로젝트 목록에서 **`iline-edu-support`** 클릭
   - 안 보이면 초대받은 계정으로 로그인했는지 확인하세요
3. 화면 **왼쪽 메뉴**에서 **`빌드`** 를 펼치고 → **`Firestore Database`** 클릭
4. 가운데 위쪽 탭 중 **`데이터`** 가 선택되어 있는지 확인

이제 화면 가운데에 세 칸짜리 목록이 보입니다. 왼쪽 칸이 **컬렉션**(자료 묶음),
가운데가 **문서**(개별 자료)입니다.

---

## 2. ⚠️ 가장 흔한 실수 — 반드시 먼저 읽어주세요

**왼쪽 첫 칸에서 `support_programs` 를 클릭하고 시작해야 합니다.**

다른 문서를 열어둔 상태에서 `컬렉션 시작` 을 누르면, 그 문서 **안에** 새 묶음이
만들어집니다. 겉보기는 똑같은데 사이트에서는 전혀 보이지 않습니다.

**확인 방법**: 화면 맨 위 경로 표시가 이렇게 되어야 합니다.

```
🏠 > support_programs
```

이런 모양이면 잘못된 것입니다 — 집 모양(🏠) 아이콘을 눌러 처음으로 돌아가세요.

```
🏠 > support_users > A1b2C3... > support_programs   ❌
```

## 3. 새 프로그램 만들기

1. 왼쪽 첫 칸에서 **`support_programs`** 클릭
2. 가운데 칸 위의 **`+ 문서 추가`** 클릭
3. **문서 ID** 입력 — 아래 설명 참고
4. 필드를 하나씩 추가 (다음 장)
5. 맨 아래 **`저장`**

### 문서 ID 정하기

이 값이 **인터넷 주소에 그대로 나옵니다.**

```
support.iline.or.kr/apply/2026-ai-workshop
                          └─ 문서 ID
```

**규칙**

- 영문 소문자 · 숫자 · 붙임표(`-`) 만 사용
- 한글·공백·슬래시(`/`) 는 넣지 마세요
- **연도로 시작**하면 나중에 목록에서 찾기 쉽습니다

**예시**

| 좋음 | 좋지 않음 | 이유 |
|---|---|---|
| `2026-ai-workshop` | `AI 수업 설계 워크숍` | 한글·공백이 주소에서 깨집니다 |
| `2026-content-dev` | `프로그램1` | 나중에 뭐가 뭔지 모릅니다 |

> ⚠️ **문서 ID는 나중에 바꿀 수 없습니다.** 바꾸려면 지우고 새로 만들어야 하는데,
> 이미 신청자가 있으면 그 신청 기록이 갈 곳을 잃습니다. **처음에 신중히** 정하세요.
> `자동 ID` 버튼도 있지만, 주소가 알아볼 수 없는 글자가 되니 **쓰지 마세요.**

## 4. 필드 입력하기

`필드 추가` 를 누르면 세 칸이 나옵니다.

```
필드 이름 [            ]   유형 [문자열 ▾]
값       [                                    ]
```

**필드 이름은 아래 표의 영문을 그대로** 적으세요. 한 글자라도 다르면 사이트가
못 알아봅니다. 대소문자도 구분합니다 (`publishedAt` ≠ `PublishedAt`).

### 반드시 넣어야 하는 것 4개

| 필드 이름 | 유형 | 값 | 설명 |
|---|---|---|---|
| `title` | 문자열 | `2026 AI 수업 설계 워크숍` | 목록·상세에 크게 보이는 제목 |
| `year` | **숫자(int64)** | `2026` | 사업 연도. **따옴표 없이 숫자만** |
| `participationType` | 문자열 | `individual` 또는 `group` | 아래 설명 참고 |
| `published` | 부울 | `false` → 나중에 `true` | 공개 여부 |

### 넣으면 좋은 것

| 필드 이름 | 유형 | 예시 | 설명 |
|---|---|---|---|
| `description` | 문자열 | `예비교원이 AI를 활용한 수업 지도안을 설계합니다.` | 한두 문장 소개 |
| `opensAt` | timestamp | 2026-09-10 09:00 | 접수 시작. **비우면 즉시 접수중** |
| `closesAt` | timestamp | 2026-09-30 18:00 | 접수 마감. **비우면 상시 접수** |
| `maxTeamSize` | **숫자(int64)** | `4` | 단체 프로그램일 때만 |

### 필요할 때만 넣는 것 — 신청서에 칸을 하나씩 추가합니다

| 필드 이름 | 유형 | 예시 | 효과 |
|---|---|---|---|
| `noteLabel` | 문자열 | `지원 동기` | 신청서에 **글쓰는 칸**이 생기고 이 이름이 붙습니다 |
| `noteRequired` | 부울 | `true` | 그 칸을 **필수**로 |
| `attachmentGuide` | 문자열 | `재학증명서를 촬영해 첨부해 주세요. 사진 또는 PDF.` | 신청서에 **파일 첨부칸**이 생깁니다 |
| `attachmentRequired` | 부울 | `true` | 첨부를 **필수**로 |

> **이 네 개를 안 넣으면** 신청서는 "내 정보 확인 후 제출" 만 있는 가장 단순한
> 형태가 됩니다. 프로그램마다 받을 것이 다른 문제를, **글칸 하나 + 첨부칸 하나**로
> 해결하도록 만들어 두었습니다. 넣는 문구만 바꾸면 되고 개발이 필요 없습니다.

## 5. 유형 고르는 법 — 화면에서 헷갈리는 부분

`유형` 을 누르면 목록이 나옵니다. 자주 쓰는 것만 설명드립니다.

| 넣을 값 | 고를 유형 | 주의 |
|---|---|---|
| 글자 | **문자열** | 기본값 |
| 숫자 (2026, 4) | **숫자** 또는 **int64** | ⚠️ 아래 참고 |
| 예/아니오 | **부울** | `true` / `false` 중 선택 |
| 날짜와 시각 | **timestamp** | 달력이 나옵니다 |

**⚠️ 숫자 유형에 대하여**

목록에 `number` 라는 이름은 없습니다. **`숫자`** 또는 **`int64`** 로 보입니다.
연도(2026)나 인원수(4)처럼 **소수점이 없는 값**은 그걸 고르시면 됩니다.

**문자열로 넣으면 안 됩니다.** `"2026"` 처럼 따옴표가 붙은 글자로 저장되면
정렬이 어긋나고 목록에서 순서가 뒤죽박죽이 됩니다.

**⚠️ 날짜(timestamp) 입력**

`timestamp` 를 고르면 **달력과 시각 선택기**가 나옵니다.
**지금 쓰고 계신 컴퓨터의 시간대(한국 시간)** 기준으로 입력됩니다.
저장 후 목록에서는 다른 시간대로 보일 수 있는데, **동작에는 문제없습니다.**

날짜는 **시각까지** 정하세요. `18:00` 으로 두면 그날 저녁 6시에 마감입니다.
`00:00` 으로 두면 **그날 시작하자마자 마감**되니 주의하세요.

## 6. `participationType` — 개인이냐 단체냐

| 값 | 언제 | 화면에서 달라지는 것 |
|---|---|---|
| `individual` | **기본값** | "개인 신청" 표시 |
| `group` | 단체 프로그램 | "단체 프로그램" 표시 + 안내 문구 + 최대 인원 |

> **지금은 둘 다 신청서가 같습니다.** `group` 을 골라도 팀원 명단을 받는 칸은
> 나오지 않고, **안내 문구만 달라집니다.** 개인으로 접수받아 현장에서 팀을 짜는
> 방식이 더 흔해서 그렇게 두었습니다. 신청 시점에 팀원 명단이 꼭 필요한
> 프로그램이 생기면 그때 만들면 됩니다.

---

## 7. 다 입력했으면 — 공개하기

1. `published` 를 **`false`** 로 둔 채 먼저 **저장**
2. 사이트에서 확인 — 담당자 계정으로 `/apply` 에 들어가면 **비공개 공고도 보입니다**
   *(학생 계정에는 안 보입니다)*
3. 내용이 맞으면 콘솔로 돌아와 `published` 를 **`true`** 로 바꾸고 저장
4. `/apply` 를 새로고침 → 목록에 나타나면 완료

### 확인할 것

- 제목·소개 문구에 오타가 없는지
- 접수 기간이 의도한 날짜인지 (**상세 화면의 "접수 기간"** 을 눈으로 확인)
- 배지가 맞는지 — `접수중` / `접수 예정` / `접수 마감`
- 신청서를 열어 **글칸·첨부칸이 의도대로** 나오는지

---

## 8. 이미 올린 공고 고치기

1. `support_programs` → 해당 문서 클릭
2. 고칠 필드의 **값 위에 연필 아이콘** → 수정 → 저장

**바로 반영됩니다.** 학생이 화면을 새로고침하면 바뀐 내용이 보입니다.

### ⚠️ 접수가 시작된 뒤에 고칠 때

| 고치는 것 | 안전한가 |
|---|---|
| 오타 수정, 소개 문구 다듬기 | ✅ 안전 |
| `closesAt` 을 **뒤로** 미루기 (연장) | ✅ 안전 |
| `closesAt` 을 **앞으로** 당기기 | ⚠️ 준비 중이던 학생이 못 냅니다. 공지 먼저 |
| `noteLabel` · `attachmentGuide` 추가 | ⚠️ **이미 낸 사람은 그 항목이 없습니다.** 따로 받아야 합니다 |
| `title` 변경 | ⚠️ 이미 낸 신청서에는 **옛 제목이 그대로** 남습니다 (일부러 그렇게 했습니다) |

---

## 9. 공고 내리기

**문서를 지우지 마세요.** `published` 를 **`false`** 로 바꾸면 목록에서 사라집니다.

> 지우면 이미 접수된 신청서가 **어느 프로그램 것인지 알 수 없게** 됩니다.
> 접수가 끝난 공고는 그냥 두시면 `closesAt` 이 지나서 **"지난 프로그램"** 칸으로
> 자동으로 내려갑니다. 지난 회차 기록으로 남기려면 **`published: true` 인 채로**
> 두세요.

## 10. 바로 쓰실 수 있는 예시

### 예시 A — 가장 단순한 개인 프로그램

```
문서 ID: 2026-ai-workshop

title              (문자열)   2026 AI 수업 설계 워크숍
year               (숫자)     2026
participationType  (문자열)   individual
description        (문자열)   예비교원이 AI를 활용한 수업 지도안을 직접 설계해 보는 프로그램입니다.
opensAt            (timestamp) 2026-09-10 09:00
closesAt           (timestamp) 2026-09-30 18:00
published          (부울)     true
```

신청서에는 **내 정보 확인 후 제출**만 나옵니다.

### 예시 B — 지원 동기와 증빙을 받는 프로그램

```
문서 ID: 2026-content-dev

title              (문자열)   2026 AI 교육 콘텐츠 공동 개발
year               (숫자)     2026
participationType  (문자열)   group
maxTeamSize        (숫자)     4
description        (문자열)   팀을 이루어 AI 기반 교육 콘텐츠를 개발합니다.
opensAt            (timestamp) 2026-10-01 09:00
closesAt           (timestamp) 2026-10-20 18:00
noteLabel          (문자열)   지원 동기 및 개발하고 싶은 콘텐츠
noteRequired       (부울)     true
attachmentGuide    (문자열)   재학증명서를 촬영해 첨부해 주세요. 사진 또는 PDF, 20MB 이하.
attachmentRequired (부울)     true
published          (부울)     true
```

## 11. 잘 안 될 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 목록에 안 보임 | `published` 가 `false` 이거나 없음 | `true` 로 |
| 목록에 안 보임 | 컬렉션을 **다른 문서 안에** 만듦 | §2 확인 — 경로가 `🏠 > support_programs` 여야 함 |
| "접수 예정" 인데 시작일이 지남 | `opensAt` 시각이 미래 | 시각까지 확인 |
| 신청 버튼이 없음 | 접수 기간 밖 | 정상 동작입니다 |
| 글칸·첨부칸이 안 나옴 | `noteLabel` / `attachmentGuide` 없음 | 그 필드를 추가 |
| 순서가 이상함 | `year` 를 **문자열**로 넣음 | 유형을 숫자로 다시 |
| 필드 이름을 틀림 | 대소문자·철자 | 표와 한 글자씩 대조 |

**그래도 안 되면** — 화면을 캡처해서 문의해 주세요. 어디를 잘못 눌렀는지는
경로 표시(🏠 > ...)만 봐도 대부분 알 수 있습니다.
