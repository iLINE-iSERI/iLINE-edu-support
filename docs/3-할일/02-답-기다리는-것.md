# A. 이것이 없으면 접수를 시작할 수 없습니다

## A-1. ⚠️ 어떤 프로그램을, 언제 접수합니까 — **가장 급함**

**사이트는 다 됐는데 올릴 공고가 없습니다.** 이것 하나가 접수 개시를
막고 있는 유일한 항목입니다.

| 무엇 | 예시 |
|---|---|
| 프로그램 이름 | `2026 교육과정 개발 워크숍` |
| 사업 연도 | `2026` |
| **접수 시작 일시** | `2026-09-15 09:00` — **분 단위까지** |
| **접수 마감 일시** | `2026-09-30 18:00` |
| 안내 내용 | 모집 대상 · 인원 · 지원 내용 · 일정 |
| 개인 신청인가 단체인가 | 대부분 **개인** |

**신청서에 무엇을 더 물어볼지도 함께 정해야 합니다.**

- **자유 기재란이 필요합니까?** 필요하면 **그 칸의 이름**
  (예: `지원 동기`, `활동 계획 요약`)
- **첨부 서류를 받습니까?** 받으면 **무엇을 내라고 안내할지** 한 줄
- 둘 다 **필수인지 선택인지**

> 📌 **접수 기간은 시스템이 강제합니다.** 시작 전에는 폼이 열리지 않고,
> 마감 후에는 제출이 거부됩니다. **날짜·시각을 정확히** 주셔야 합니다.

**답이 없으면**: 접수를 시작할 수 없습니다. 주시면 등록은 10분입니다.

## A-3. 담당자는 누구입니까

검토·선정·정산을 처리할 분의 **구글 계정 또는 가입 이메일**이 필요합니다.
두 가지를 해드려야 합니다.

1. 사이트 **담당자 권한** 부여
2. **구글 시트·공유 드라이브** 초대

> ⚠️ 담당자가 바뀌면 **두 곳 모두 회수**해야 합니다. 사이트만 막고 시트
> 공유를 안 풀면 개인정보가 계속 보입니다.

**답이 없으면**: 관리자(iSERI) 계정 하나로 운영됩니다. 교수님이 직접
확인하시려면 교수님 계정에도 권한이 필요합니다.

## A-4. 개인정보처리방침·이용약관에 들어갈 내용

> **09-08 교수님: "내용은 다시 줄게. 우선은 그대로 두고, 수정해야 한다는
> 것만 기억해."** → 대기 중. 화면에는 **"초안"** 표시가 붙어 있습니다.

받아야 하는 것:

- **개인정보 보호책임자** — 성명 · 직위
- **연락처** — 문의처와 같아도 되는지
- **시행일**
- 🆕 **이용 목적에 "선정 결과 공고"** — 선정자 명단을 공지에 올리기로 했으므로
  (D-46) 근거가 방침에 있어야 합니다

**기관 행정·법무 검토도 필요합니다.** 함께 확인할 것:

- 보유기간 **"사업 종료 후 3년"** 이 사업 규정과 맞는지
- **구글 스프레드시트·드라이브** 이용에 대한 처리위탁·국외이전 기재 필요 여부
  (현재 Google, Vercel 두 곳을 위탁받는 곳으로 적어두었습니다)

> ✅ 검토 요청하실 때 함께 알려드리면 좋은 것: **사이트는 신분증·통장 사본을
> 받지 않습니다.** 보유하는 것은 **가입 정보 + 지급 계좌 + 영수증**이 전부이고,
> **계좌는 구글로 내보내지 않습니다.**

**답이 없으면**: "초안" 표시가 계속 붙습니다. **공개 상태로 접수를 받는 것은
권하지 않습니다.**

## A-5. 🆕 선정자 목록에 무엇을 적을지

D-46으로 **결과를 공지사항에 올리기로** 하면서 새로 생긴 항목입니다.

> 🔴 **공지사항은 로그인 없이 누구나 봅니다.** 선정자 명단을 올리는 것은
> **개인정보 공개**입니다.

- **무엇을 적을지** — 이름만 / 이름 + 학번 뒤 4자리 / 소속까지?
  *(동명이인이 있으면 이름만으로는 본인 확인이 안 됩니다)*
- **처리방침 근거** → A-4에 포함해 요청
- 공지를 **회원만 보이게** 하는 기능은 지금 없습니다. 필요하면 만듭니다

**답이 없으면**: 담당자가 그때그때 판단하게 되어 회차마다 달라집니다.

# B. 정해두면 좋은 것 (답 없으면 괄호 안대로 갑니다)

## B-2. 서식 자료실을 씁니까

알림마당 아래 **서식 자료실**이 비어 있습니다. 신청서는 웹에서 바로 쓰므로
**따로 배포할 서식이 실제로 있는지**가 관건입니다.

- 있다 → 파일 주시면 올리는 기능을 만듭니다
- 없다 → 메뉴에서 내립니다

**기본값: 메뉴에서 내립니다.** (공고문 파일은 공지사항에 붙이면 됩니다)

## B-4. 신청 상태 이름이 적절합니까

신청자에게 이렇게 보입니다:

> **제출 완료 · 검토 중 · 보완 요청 · 선정 · 미선정 · 취소됨**

재단·학교의 공식 표현이 따로 있으면 맞추는 편이 낫습니다.

**기본값: 현행 유지.**

## B-5. 초상권 동의서 문구 확인

촬영 동의를 **회원가입이 아니라 프로그램 신청할 때** 받도록 바꿨습니다(D-44).
사진은 특정 프로그램 활동에서 찍히고, 같은 사람이 프로그램마다 다르게
판단할 수 있기 때문입니다. **동의하지 않아도 참여에 제한은 없습니다.**

문구에 **활용 범위**(자료집·홈페이지·SNS·보도자료)와 **보관 기간**이
들어 있습니다. 사업 규정과 어긋나는 표현이 없는지 봐주시면 좋겠습니다.
→ 화면: 신청서 맨 아래 「촬영·초상권 동의」

**기본값: 현행 유지.**

# C. 접수 시작한 뒤에 답하셔도 되는 것

| 항목 | 지금은 |
|---|---|
| 개인/단체 지원금·심사 기준 차이 | 개인 신청 기준 |
| 정산 기한 — 언제까지 내야 하는지 | 기한 없음 (언제든 제출) |
| 지급 완료 표시 — 실제 이체 여부를 사이트에 남길지 | 상태는 제출/승인/반려뿐 |
| 정산을 상단 메뉴로 뺄지 | 마이페이지 안, 선정 건에만 노출 |
| 회원정보 수정 화면을 만들지 | **화면 없음** — 담당자 문의로 옵니다 |
| 담당자 첫 화면을 갈림길로 만들지 | 신청 목록이 첫 화면 |
| 예상 신청 규모 | 소규모 가정 |
| 갤러리 공개 승인 주체 · 초기 콘텐츠 | 갤러리 자체가 보류 (D-47) |
