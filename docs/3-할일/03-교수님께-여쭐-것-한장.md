## ③ 산출물·활동 사진 제출 페이지 — 어떻게 쓰실지

미팅에서 "진행 중에 활용할 페이지"를 **참여자가 산출물과 사진을 올리는 곳**으로
이해했습니다. 만들기 전에 다섯 가지만 정해 주세요.

| 정할 것 | 예시 | 답 |
|---|---|---|
| **무엇을** 올리나 | 지도안 · 보고서 · 활동 사진 · 영상 링크 | |
| **언제** 올리나 | 프로그램 기간 중 아무 때나 / 담당자가 정한 제출 기간에만 | |
| **개인인가 팀인가** | 팀 프로그램은 대표자가 팀 이름으로 한 번 | |
| 올린 것을 **누가 보나** | 담당자만 / 본인+담당자 / 참여자 전체 / 누구나(갤러리) | |
| 담당자가 **검토·반려**를 하나 | 한다 (보완 요청 가능) / 안 한다 (제출로 끝) | |

*사진을 갤러리에 공개하려면 그 사진에 찍힌 사람의 초상권 동의가 있어야 하므로,
"누구나" 공개는 담당자가 사진마다 골라 올리는 방식이 됩니다.*
