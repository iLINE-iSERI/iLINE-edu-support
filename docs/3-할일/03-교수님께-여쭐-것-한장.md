## ③ 산출물·활동 사진 제출 페이지 — **이렇게 만들었습니다** (답 불필요)

미팅에서 "진행 중에 활용할 페이지"를 **참여자가 산출물과 사진을 올리는 곳**으로 이해하고
만들었습니다. 상단 메뉴 **「산출물 제출」** 입니다. 읽어 보시고 다르게 원하시는 것만 알려 주세요.

| 정할 것 | 이렇게 됩니다 |
|---|---|
| **무엇을** 올리나 | **자유롭게** — 글을 쓰고 파일을 여러 개 붙입니다. 지도안·보고서·사진을 가리지 않습니다 |
| **언제** 올리나 | **활동 기간 중 아무 때나.** "○월 ○일까지"로 조이고 싶으면 공고의 **제출 기한 칸**에 넣습니다 |
| **개인인가 팀인가** | 팀 프로그램은 **팀원 누구나** 올릴 수 있고 팀 단위로 묶여 보입니다 |
| 올린 것을 **누가 보나** | **공고마다 담당자가 고릅니다** — 본인+담당자만 / 참여자끼리 공유(이름 없이 팀명만) |
| 담당자가 **검토·반려**를 하나 | **없습니다.** 내면 바로 접수되고, 담당자는 필요할 때 **추가 요청**만 남깁니다 |

**사진 속 다른 사람** — 참여자끼리 공유하면 함께 찍힌 사람의 동의 문제가 생깁니다. 그래서
ⓐ 올릴 때 "다른 사람이 나오는 사진은 동의를 받고 올려 주세요" 안내가 뜨고, ⓑ 문제가 된 사진은
담당자가 **내릴 수 있게** 했습니다(기록은 남고 화면에서만 사라짐). 개인정보처리방침에도 이 근거를
넣었습니다(①의 「산출물 제출·참여자 공유」 줄).
