검색으로도 들어올 수 있습니다. 그래서 명단에 실명을 그대로 올리면 지원한 사실과 이름이
인터넷에 남습니다.

| 어떻게 적을까요 | 예시 | 답 |
|---|---|---|
| 팀명만 | 「AI드림팀」 | |
| 팀명 + 대표자 성 | 「AI드림팀 (김OO)」 | |
| 실명 그대로 | 「AI드림팀 (김철수)」 | |
| 명단을 안 올리고 개별 통지만 | 사이트 마이페이지에서 본인만 확인 | |

*답이 없으면 **팀명만** 올리고, 자세한 것은 개별 통지로 하겠습니다 — 되돌리기 쉬운 쪽입니다.*

## ⑧ 🆕 「서식 자료실」을 쓸까요, 내릴까요

알림마당 아래에 **「서식 자료실」** 이라는 화면이 있는데 **지금 비어 있습니다.** 한편 교수님이
요청하신 **공지사항 첨부파일**을 만들면 공지에 파일을 붙일 수 있게 됩니다. 둘이 겹칩니다.

| 어떻게 | 이렇게 됩니다 | 답 |
|---|---|---|
| **공지 첨부만 쓴다** | 자료실 메뉴를 내립니다. 서식은 공지에 붙여 올립니다 | |
| **둘 다 쓴다** | 자료실은 **늘 쓰는 서식**(신청서·정산 양식), 공지 첨부는 **그 공지에만** 딸린 파일 | |

*답이 없으면 **메뉴에서 내립니다** — 비어 있는 메뉴가 있는 것이 더 나쁩니다.*

## ⑨ 🆕 신청 상태 이름이 적절한가요 (답 불필요 — 바꾸고 싶으면)

신청자와 담당자가 보는 상태 이름입니다. 어색한 것이 있으면 알려 주세요.

신청자에게 보이는 이름과 담당자에게 보이는 이름이 **일부러 다릅니다** — 같은 사실을
보는 자리가 달라서입니다.

| 신청자(마이페이지) | 담당자(관리 화면·시트) |
|---|---|
| **검토 중** — 내 신청서가 담당자 손에 있다 | **미처리** — 내가 아직 안 봤다 |
| 보완 요청 | 보완 요청 |
| 선정 / 미선정 | 선정 / 미선정 |
| 취소됨 | 취소됨 |

*(저장되는 값은 하나입니다. 신청서 PDF 에는 상태가 들어가지 않습니다 — 제출 시점 원본이라.)*

## ⑩ 🆕 협력기관 **로고**를 사이트에 써도 될까요

사업소개 화면의 **「협력체계」** 칸에 지금은 기관 이름을 **글자로만** 적어 두었습니다.
로고 이미지로 바꾸면 훨씬 보기 좋은데, **다른 기관의 로고를 쓰는 것이라 허락이 필요합니다.**

지금 적혀 있는 다섯 곳입니다:

| 기관 | 로고를 써도 되는지 |
|---|---|
| 제주대학교 | |
| 제주대학교 사범대학 | |
| 지능소프트웨어교육연구소 | |
| **제주특별자치도교육청** | |
| **제주지방기상청** | |

🔴 **굵게 표시한 두 곳은 우리 대학 밖의 기관**이라, 로고 사용에 별도 승인이나 사용 지침이
있을 수 있습니다. 써도 되는지, 된다면 **로고 원본 파일**을 어디서 받으면 되는지 알려 주세요.

*답이 없으면 지금처럼 **기관 이름 글자**로 둡니다 — 허락 없이 쓰는 것보다 안전합니다.*
