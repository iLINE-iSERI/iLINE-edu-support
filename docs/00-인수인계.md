## 2. 작업 규칙 (반드시)
- 저장소: Next.js 14 App Router · TypeScript · Tailwind 3.4 · Firebase(Auth/Firestore/Storage + Admin) · Vercel · Pretendard. 로컬은 `.env.local` 이 있으니 `npm run dev` 로 실제 동작 확인 가능. 타입체크 `npx tsc --noEmit -p .`.
- **규칙 파일(firestore.rules / storage.rules)이 바뀌면 push 뒤 `npm run rules`** — 안 하면 새 컬렉션 쓰기가 전부 "권한 없음". Firebase 자격이 필요한 명령(`npm run rules`, `grant-staff.mjs`)은 사용자가 직접 돌린다.
- **보안**: 서비스 계정 JSON·Firebase admin 키·Vercel/GitHub 토큰·`.env.local` 내용은 채팅에 절대 안 넣음. `FIREBASE_PRIVATE_KEY` 복사 금지(`FIREBASE_CLIENT_EMAIL`은 됨). 시트·드라이브로 나가는 것은 이름·학번·전공·학년·연락처·이메일·동의 여부·증빙서류까지. **계좌(bankInfo)는 절대 반출 금지.** 산출물 파일·제출자 이름은 시트로 안 나감. 반출 범위는 `docs/4-기록/02-시트-드라이브-반출-범위.md`.
- `docs/작업지시서.md`를 항상 갱신(D-번호 행 추가 + 맨 위 「최종 개정」 판 번호 + 아래 판 이력 표 — **셋 다**; 09-21 에 판 번호가 빠져 있어 보정했음). 무엇을 왜 했는지, 지시서와 다르게 한 것을 보고. 휴대폰 대응 필수(D-24). 교수님용 문서는 🔴=결정 필요, 쉬운 말, D-번호·코드 경로 없음. **새 문서 파일을 만들지 말고 기존 문서에 쓴다.** `Claude outputs/` 커밋 금지.
- 코드 규칙: **prettier를 통째로 돌리지 않는다**(⑫). 새 글자 크기는 rem. 같은 속성 유틸리티를 조건 없이 겹치지 않는다(⑬ — `font-medium` + 조건부 `font-bold`는 빌드 CSS 알파벳순 때문에 bold가 진다). 임시 화면(`app/zz-*`, `public/`)은 납품 전 삭제. **lib/ 에 적은 Tailwind 클래스는 `tailwind.config` content에 `lib/**`가 있어야 나간다**(09-18 추가됨).
- 토큰은 `globals.css`에 「R G B」 세 숫자, `tailwind.config.ts`가 `rgb(var() / <alpha-value>)`로 감쌈 → `bg-x/12` 투명도가 통한다.
- **무조건 찬성하지 말고 비판적으로 검토해 의견을 준다.** 결정은 사용자에게 묻고(AskUserQuestion), 시안을 먼저 보여준다. Gemini가 쓴 디자인 지시서가 오면 현재 코드와 대조해 큰 편차·위험을 먼저 짚고, 적용 뒤 "지시서와 다르게 한 것"을 명시. 반복 거절된 것: 글자색 #64748B/#94A3B8(대비 낙제), 헤더 72%(85% 유지), 카드 radius 14px(16 유지).
