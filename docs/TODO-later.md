## ⚠️ 코드를 고친 뒤 배포까지 확인하는 순서

로컬에서 되는 것과 배포된 사이트에서 되는 것은 다릅니다.
**Vercel 은 GitHub 에 있는 코드로 배포합니다.**

1. 로컬에서 확인
2. `git add . && git commit -m "..." && git push`
3. Vercel 이 자동 재배포 (1~2분)
4. **배포된 주소에서 다시 확인**

*(09-05: push 를 빠뜨려 배포본에만 옛 코드가 남아 신청서 제출이 실패한 적 있음)*

콘솔에 따로 게시해야 하고, push 로는 반영되지 않습니다.
