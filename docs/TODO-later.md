- [ ] 규칙 게시 — 레포의 `firestore.rules` · `storage.rules` 를 **통째로** 붙여넣기

### A-4. 이후

- [ ] **`.env.local.txt` 를 Git 추적에서 제거**
      ```

      ```

      앞으로 서비스 계정 키를 같은 파일에 적으면 그대로 커밋됩니다)*

      matcher가 거의 모든 경로에 걸려 있는데 하는 일이 없음
- [ ] **`sitemap.xml` · `robots.txt` 신규 작성** — 현재 둘 다 없음(404 확인)
- [ ] 루트 페이지 교체 + `href="/"` **7곳**을 `/home` 으로 (D-21, 파일 9개)

- [ ] 침투 시나리오 점검 — 남의 신청서·정산 증빙에 접근되는지
- [ ] **담당자 운영 매뉴얼** — 특히 *"시트에서 상태를 고쳐도 사이트에 반영되지 않는다"* 명시
- [ ] **담당자 지정·회수 이력 기록** — 감사 대응. 권한이 두 종류라 회수 시 둘 다 되돌려야 함
- [ ] **고아 파일 정리 방법** — 제출이 중간에 실패하면 Storage에 올라간 첨부만 남고
      문서는 안 만들어집니다. 어디에도 연결되지 않은 파일이라 화면에는 안 보이지만
      용량은 차지하고 개인정보이기도 합니다. *(09-05 실제 발생 확인)*
      선택지: ① 주기적 정리 스크립트 ② Storage 수명 주기 규칙 ③ 운영 중 수동 확인
- [ ] 개인정보 보유기간 만료 시 **파기 절차** — Storage와 공유 드라이브 **두 곳** 모두
- [ ] **로그인 유지 정책 결정** — 현재는 Firebase 기본값(브라우저에 저장, 창을 닫아도 유지).
      편의상 맞지만 **공용 PC에서 로그아웃하지 않고 나가면 다음 사람이 그대로 들어옵니다.**
      선택지: ① "로그인 유지" 체크박스로 세션 한정 저장 ② 일정 시간 무활동 시 자동 로그아웃 ③ 현행 유지 + 안내 문구
      *(인증 흐름을 다시 건드리는 일이라 신청서 확정 후에 처리 — 09-05 확인)*
