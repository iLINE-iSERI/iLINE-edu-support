>

> 나옵니다. **단체대관용 카드도 넷째로** 보이며, 고르면 격자 대신 문의 안내가
> 뜹니다 — "없는 것"이 아니라 "문의로 받는 것"임을 처음부터 보여 주기 위해.
> 마우스 올렸을 때만 설명이 나오는 방식은 **휴대폰에 마우스가 없어** 쓰지 않았습니다(D-24).

## 0. 화면 목록

| | 화면 | 누가 |
|---|---|---|
| **1** | **예약하기** | 회원 |
| **2** | **내 예약** (조회·취소) | 회원 |
| **3** | **행정실 전달 명단** 🔴 | 담당자 |
| **4** | **예약 현황** (오늘 / 주간) | 담당자 |
| **5** | **직접 예약 추가** 🔴 | 담당자 |
| **6** | 운영 설정 (마감 요일·휴관일) | 담당자 |

🔴 는 **없으면 운영이 안 되는** 화면입니다. 3번은 목요일 업무 그 자체이고,
5번은 단체대관·당일·주말 문의가 **전부 들어오는 통로**입니다.

**메뉴 위치** — 상단 대메뉴에 **「시설 예약」** 을 둡니다(09-10 확정).
매주 들어오는 화면이라 마이페이지 안쪽에 두면 번거롭습니다.

```
사업소개 · 프로그램 신청 · 시설 예약 · 알림마당
                            └ 예약하기 · 내 예약
```

## 1. 예약하기

### 1-1. 맨 위 — **지금 어떤 상태인지**

이 화면에서 **가장 중요한 부분**입니다. 들어온 사람이 제일 먼저 알아야
할 것은 **"어느 날짜까지 고를 수 있고, 언제 확정되는가"** 입니다.

```
📅 9/21(월) ~ 10/16(금) 사이에서 고르실 수 있습니다
   9/16(수) 18:00까지 예약하시면 9/17(목)에 행정실로 전달됩니다

   그 전에 쓰셔야 하거나, 주말·18시 이후에 쓰시거나, 이용 당일에 시간을 더
   쓰고 싶으시면 현장 관리자에게 문의해 주세요 ☎ ○○○-○○○○
```

*(09-12: "당일에 시간을 더 쓰고 싶은 경우"도 문의로 푸는 경우에 넣음 — iSERI)*

**예약은 항상 열려 있습니다.** 「마감」은 사이트를 닫는 것이 아니라
**고를 수 있는 첫 날짜를 한 주 뒤로 미루는 것**입니다(D-55). 그래서
"마감되었습니다" 화면이 **없어졌습니다.**

화면이 두 날짜를 계산합니다.

| | 계산 |
|---|---|
| **첫 날짜** | 이번 주 마감(수 18:00) **전**이면 다음 주 월요일, **지나면** 다다음 주 월요일 |
| **끝 날짜** | 첫 날짜가 있는 주부터 **4주째 금요일** |

> 왜 다다음 주인가 — 수요일 18시가 지나서 넣은 예약은 **다음 목요일**에
> 나갑니다. 다음 주 이용분을 그때 보내면 이미 지난 뒤입니다.

> ⚠️ **문의 안내는 여전히 필수**입니다 (D-53). 이번 주·다음 주처럼
> 고를 수 없는 날을 눌렀을 때도 같은 안내가 떠야 합니다 — "안 됩니다"로
> 끝내면 못 쓰는 줄 압니다.

**이미 그 날짜에 이 공간 예약이 있는 경우** — 공간마다 하루 1건이므로 그 날은 고를 수 없습니다(09-12 개정). 다른 공간 예약과 **겹치는 시각**도 취소선으로 막힙니다.
막기만 하지 말고 **왜 못 고르는지**를 적습니다.

```
9/22(화)는 이미 예약하셨습니다 → 내 예약 보기
```

### 1-2. 공간 고르기 — 탭 세 개

```
[ 미디어·블렌디드 랩 ]  [ 개인·협업 학습실 ]  [ 그룹 스터디룸 ]
   랩실 3개 · 4명           좌석 12개 · 1인        테이블 4개 · 6명
   영상 제작·편집·온라인 수업   개인 학습·집중       팀 프로젝트·토론·발표
```

### 1-3. 날짜·시간 — **주간 격자 + 주 이동**

달력을 만들지 않습니다. 한 주가 **월~금 다섯 열**이고, 화살표로 주를
옮깁니다. 4주 범위이니 화살표는 **최대 세 번**만 갑니다.

```
  ◀  9/21(월) ~ 9/25(금)  ▶            ← 범위 밖에서는 화살표가 흐려짐

        9/21(월)  9/22(화)  9/23(수)  9/24(목)  9/25(금)
09:00     3         3         2         －         3
10:00     2         3         0         －         3
11:00     2         1         0         －         3
12:00     3         3         3         －         3
13:00     3         2         3         －         3
   ⋮
17:00     3         3         3         －         1

숫자 = 남은 자리 수 ·  0 = 다 참 ·  － = 휴관
```

- 숫자를 **그대로 보여줍니다.** "가능/불가"만 있으면 *"지금 들어가면
  잡을 수 있나"* 를 알 수 없습니다
- **휴관일은 `－` 로 구분**합니다. "다 참"과 "아예 안 엽니다"는 뜻이 다릅니다(J-7)
- 주말은 **열에 나오지도 않습니다**
- **첫 화면은 고를 수 있는 첫 주**입니다. 이번 주·다음 주처럼 고를 수 없는
  주는 화살표로 가 볼 수는 있되, 격자 전체가 흐리고 위에 이유가 뜹니다 —
  *"이번 주는 이미 행정실에 전달되었습니다 · 급하시면 문의 ☎"*
- **공간마다 하루 1건**이라 이 공간에 이미 예약한 날은 열 전체가 흐려집니다 (§1-1 문구)

**시간은 「시작 시각 + 길이」로 받습니다.**

```
선택: 9/22(화) 14:00 부터   [ 1시간 ]  [ 2시간 ]
```

칸을 두 번 눌러 이어 붙이게 하면 **떨어진 두 칸을 고르는 실수**가 나옵니다.
길이를 고르게 하면 그 실수가 생기지 않고, 2시간 뒤가 막혀 있으면
**[2시간] 버튼을 흐리게** 만들어 그 자리에서 알려줄 수 있습니다.

### 1-4. 자리 — **개인 좌석만 고르고, 나머지는 자동**

시간을 고른 **다음에** 자리를 정합니다. 이 순서면 **되돌아갈 일이 없습니다** —
이미 그 시간에 비어 있는 것만 보여주기 때문입니다.

| 공간 | 어떻게 |
|---|---|
| **개인 좌석** | 그 시간에 **비어 있는 좌석만** 배치도로 보여주고 고르게 합니다. 창가·구석처럼 **위치 선호가 실제로 있습니다** |
| 미디어랩 · 그룹 테이블 | **자동으로 하나** 배정합니다. `[자리 바꾸기]` 로 다른 것을 고를 수 있습니다 |

```
빈 좌석을 고르세요 — 9/22(화) 14:00~16:00

 [01] [02] [03] [04]        ▨ = 이미 예약됨
 [05] ▨   [07] [08]
 [09] [10] ▨   [12]
```

### 1-5. 확인 → 완료

**신청자 정보는 입력할 것이 없습니다**(D-52). 확인만 합니다.

```
공간   개인·협업 학습실 · 07번 좌석
일시   2026. 9. 22.(화) 14:00 ~ 16:00 (2시간)
이름   홍길동 (학생 · 제주대학교 초등교육과)
연락처 010-****-5678

□ 이용 수칙을 확인했습니다
  · 이용 후 자리를 정리해 주세요
  · 못 오시게 되면 「내 예약」에서 미리 취소해 주세요

              [ 예약 신청하기 ]
```

완료 화면은 **"예약되었습니다"라고 말하지 않습니다**(D-53).

```
✅ 예약 신청이 접수되었습니다

   ST-260922-K3QD

   9/17(목)에 사범대학 행정실로 사용 요청이 전달되며,
   그때 확정됩니다. 확정되면 「내 예약」에 표시됩니다.

   [ 내 예약 보기 ]   [ 홈으로 ]
```

## 2. 내 예약

```
┌────────────────────────────────────────────┐
│ 접수됨   ST-260922-K3QD                     │
│ 개인·협업 학습실 · 07번 좌석                  │
│ 9/22(화) 14:00 ~ 16:00                      │
│                                             │
│ 9/17(목)에 행정실로 전달되면 확정됩니다        │
│                              [ 예약 취소 ]  │
└────────────────────────────────────────────┘
```

**상태는 둘**입니다 — `접수됨` → `확정됨`. (그 밖에 `취소됨`)

4주 범위이므로 **확정된 뒤에도 취소가 생깁니다** (3주 뒤 계획은 바뀝니다).
그래서 취소는 **이용일 전까지 언제든** 누를 수 있고, 어느 상태였는지에
따라 뒤처리가 다릅니다.

| 취소할 때 상태 | 무슨 일이 |
|---|---|
| `접수됨` (아직 안 보냄) | 그냥 사라집니다. 행정실은 몰라도 됩니다 |
| `확정됨` (이미 보냄) | **다음 목요일 명단의 「취소」 묶음**으로 행정실에 알립니다 (§3) |

확정된 것을 취소할 때는 그 뜻을 적어 줍니다.

> 이 예약은 이미 행정실에 전달되었습니다. 취소하시면 다음 목요일에
> 취소 사실도 함께 전달됩니다.

*(이용일 몇 시간 전까지로 좁힐지는 J-5 그대로 미결)*

## 3. 행정실 전달 명단 🔴 — **이 시스템의 핵심 산출물**

목요일에 담당자가 여는 화면입니다. **손으로 정리하지 않아도 되게** 만드는
것이 전부입니다.

**무엇을 보내나 — "다음 주 이용분"이 아니라 「지난 전달 이후 들어온 것 전부」**
(D-55). 받는 범위(4주)와 보내는 범위가 다르면 사람이 골라내야 하고,
그게 바로 없애려던 손작업입니다. 그래서 명단은 **날짜가 아니라 상태**로
뽑습니다 — *아직 안 보낸 접수 건* + *보낸 뒤 취소된 건*.

```
행정실 전달 명단 — 9/17(목)                    [ 인쇄 ] [ 복사 ]
지난 전달: 9/10(목) · 그 뒤로 들어온 것

■ 새 사용 요청 (12건)

미디어·블렌디드 랩
  9/21(월) 10:00~12:00  랩실 2   홍길동  교육학과  010-1234-5678
  10/6(화) 14:00~16:00  랩실 1   김철수  컴퓨터교육 010-2345-6789

개인·협업 학습실
  9/22(화) 14:00~16:00  07번    이영희  초등교육  010-3456-7890
  ...

그룹 스터디룸
  ...

■ 취소 (2건) — 지난번에 보낸 것 중 취소됨

  9/23(수) 09:00~11:00  랩실 3   박민수   (9/10 전달분)
  9/24(목) 13:00~14:00  02번    최지우   (9/3 전달분)

새 요청 12 · 취소 2

        [ 행정실 전달 완료 — 위 14건을 처리한 것으로 기록합니다 ]
```

- **두 묶음**입니다. 새 요청은 `확정됨`으로, 취소는 "행정실도 알게 됨"으로
  표시가 바뀝니다. 취소 묶음이 없으면 그 부분은 아예 안 나옵니다
- **공간별로 묶고 날짜순**으로 정렬합니다. 여러 주가 섞이므로 날짜를
  **월/일까지** 반드시 적습니다 (요일만 적으면 어느 주인지 모릅니다)
- ~~**[복사]** 는 메일에 그대로 붙일 수 있는 글자로 복사합니다~~ → **09-12 뺌.**
  행정실에 어떻게 전달할지는 운영진이 정하므로(iSERI) 메일을 전제한 기능은
  두지 않습니다. 목록과 [인쇄]만
- **[전달 완료]** 는 **화면에 떠 있던 그 건들만** 바꿉니다. 버튼을 누르는
  사이에 새로 들어온 예약은 다음 주로 넘어가야지, 보내지도 않았는데
  확정되면 안 됩니다. 전달하는 행위와 상태 변경이 **같은 순간**이라
  어긋날 수 없습니다(D-53)
- 목요일이 아닌 날 열어도 **똑같이 됩니다.** 주 2회 전달로 바꾸는 날이
  와도 이 화면은 그대로입니다

⚠️ **되돌리기**를 만들어야 합니다. 잘못 눌렀을 때 방법이 없으면 안 됩니다.
가장 단순한 방법: 전달 한 번을 **묶음 하나**로 기록하고, 마지막 묶음만
`[되돌리기]`로 풀 수 있게 합니다.

## 4. 예약 현황 (담당자)

**「오늘」 과 「주간」 두 가지**로 봅니다.

- **오늘** — 현장 관리에 씁니다. 지금 어느 자리에 누가 있는지
- **주간** — 예약하기와 같은 격자(◀ ▶ 주 이동 포함). 다만 숫자 대신
  **누가 잡았는지**, 그리고 `접수됨`/`확정됨` 을 색으로 구분

각 칸에서 **[취소]** 와 **[메모]** 를 할 수 있어야 합니다.

**🔄 09-12 만들면서 바꾼 것** — 주간 격자 대신 **날짜 하나씩 목록**(오늘이
기본, 요일 탭에 건수)으로 만들었습니다. 이름이 들어가면 칸에 안 들어가고,
담당자에게 실제로 필요한 것은 "그 날 누가 언제 어디"이기 때문입니다.
주말도 탭에 나옵니다 — 직접 넣은 주말 대관을 확인해야 하므로.

## 5. 직접 예약 추가 🔴 (담당자)

**단체대관 · 당일 · 주말 · 야간이 전부 이 통로로 들어옵니다**(D-53).

일반 예약과 다른 점:

| | 회원 예약 | 담당자 직접 추가 |
|---|---|---|
| 마감 | 지켜야 함 | **무시** |
| 공간마다 하루 1건 | 지켜야 함 | **무시** |
| 최대 2시간 | 지켜야 함 | **무시** (대관은 종일도 가능) |
| 주말·야간 | 못 고름 | **고를 수 있음** |
| 자리 | 하나 | **여러 개 한 번에** (12석 전체 등) |
| 이름 | 회원 정보에서 | **직접 입력** (단체명도 가능) |

```
공간   [개인·협업 학습실 ▾]
자리   □전체  ☑01 ☑02 ☑03 …
날짜   [2026-09-26]  ← 주말도 고를 수 있음
시간   [09:00] ~ [18:00]
이름   [교육학과 스터디 동아리]     ← 회원이 아니어도 됨
연락처 [010-...]
메모   [학과 워크숍 · 행정실 협의 완료]

                        [ 추가 ]
```

⚠️ **회원 예약과 같은 잠금(슬롯 문서)을 씁니다.** 그래야 그 시간에 회원이
같은 자리를 예약하지 못합니다. 이게 빠지면 이중 예약이 납니다.

**🔄 09-12 만들면서 정한 것** — ① 자리마다 예약 문서를 하나씩 만듭니다
(슬롯 → 예약이 1:1이어야 취소·되돌리기가 단순합니다) ② 「행정실과 이미
협의됨 → 바로 확정」이 **기본 체크**입니다. 대관은 문의 단계에서 행정실과
조율을 끝내고 넣는 것이 운영 방안 §3의 순서라서. 체크를 풀면 접수됨으로
들어가 다음 명단에 실립니다.

## 7. 상태별 화면 — **빠뜨리기 쉬운 것들**

| 언제 | 무엇을 보여주나 |
|---|---|
| 로그인 안 함 | 로그인으로 보냈다가 **돌아옵니다** (신청 화면과 같은 방식) |
| 회원 등록 미완료 | 회원 등록 화면으로 |
| **고를 수 없는 주** (이번 주·마감 지난 다음 주) | 격자 흐림 + 이유 + **문의 안내** (~~접수 마감 화면~~은 없어짐, D-55) |
| **범위 밖 (4주 뒤)** | 화살표 흐림 — *"○/○까지 예약할 수 있습니다"* |
| **그 날 이미 예약함** | 열 흐림 + 어느 예약인지 + 「내 예약」 링크 |
| **그 시간 자리가 다 참** | 격자에 `0` — 누르면 *"다른 시간을 골라주세요"* |
| **휴관일** | 격자에 `－` — 누르면 *"휴관일입니다"* |
| 예약이 하나도 없음 | *"아직 예약이 없습니다"* + [예약하기] |
| **확정된 것을 취소** | *"이미 전달됨 — 취소도 목요일에 함께 전달"* 확인창 |
| **전달할 것이 없음** (담당자) | *"지난 전달 이후 새 요청·취소가 없습니다"* — 빈 표를 보내지 않게 |

## 8. 모바일 (D-24)

**격자가 문제입니다.** 5일 × 10시간을 좁은 화면에 넣을 수 없습니다.

→ 휴대폰에서는 **하루씩** 봅니다.

```
◀  9/22(화)  ▶        ← 좌우로 날짜 이동 (주말은 건너뜀, 4주 범위 끝에서 멈춤)

09:00  자리 3개 남음   >
10:00  자리 2개 남음   >
11:00  다 참
   ⋮
```

날짜 하나씩 넘기면 4주 = 20번이라, 위에 **주 고르기** 한 줄을 둡니다
(`9/21주 · 9/28주 · 10/5주 · 10/12주`). 누르면 그 주 월요일로 갑니다.

좌석 배치도는 **4열 그대로** 둡니다(12칸이라 좁은 화면에도 들어갑니다).
