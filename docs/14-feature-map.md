# 어떤 기능이 어디에 있는가 — 화면 지도

> **교수님·담당자와 함께 보면서 "이 기능은 여기 말고 저기가 낫겠다"를 의논하기 위한 문서**입니다.
> 기술 설명이 아니라 **어디를 눌러 들어가는지**를 기준으로 적었습니다.
> 기능을 새로 만들거나 옮기면 **이 문서를 함께 고칩니다.**
>
> 기준일: 2026-09-06 · 운영 주소 `i-line-edu-support.vercel.app`
> (`support.iline.or.kr` 연결 예정)

## 0. 한눈에

사이트는 **보는 사람에 따라 세 겹**입니다. 로그인하면 메뉴가 늘어나는 구조라,
같은 주소로 들어가도 사람마다 보이는 것이 다릅니다.

```
① 누구나            사업소개 · 프로그램 목록 · 갤러리 · 알림마당 · 약관
                    └ 로그인 없이 봅니다. 공고를 읽는 것까지가 여기.

② 회원(신청자)      + 마이페이지 (신청서 제출 · 신청 현황 · 정산)
                    └ 로그인하면 헤더 오른쪽에 [마이페이지]가 생깁니다.

③ 담당자            + 신청 관리 (그 안에 프로그램·공지·정산 관리)
                    └ 담당자 권한이 있으면 헤더에 [담당자]가 하나 더 생깁니다.
```

**중요**: ③은 ②를 포함합니다. 담당자도 회원이라 마이페이지를 갖습니다.

## 1. 누구나 볼 수 있는 곳 — 상단 메뉴 4개

헤더의 주 메뉴입니다. 로그인 여부와 상관없이 늘 보입니다.

| 메뉴 | 무엇이 있나 | 지금 상태 |
|---|---|---|
| **사업소개** | 사업 개요·추진 체계 안내 | 내용 채워짐 |
| **프로그램 신청** | 공고 목록 → 상세 → 신청서 | **동작 중** |
| **갤러리** | 산출물·활동사진 | ⏸ **아직 빈 화면** |
| **알림마당** | 공지사항 · 서식 자료실 · FAQ | 공지 **동작 중**, 나머지 빈 화면 |

**하단(푸터)**: 이용약관 · 개인정보처리방침 · FAQ · iLINE 사이트 링크

### 프로그램 신청 — 안에서 이렇게 갈라집니다

```
프로그램 신청
 ├ 접수중 · 예정   ← 지금 낼 수 있거나 곧 열리는 공고
 └ 지난 프로그램   ← 마감된 공고 (기록용으로 남습니다)
        │
        └ 공고를 누르면 → 상세 → [신청서 작성]
                                    └ 로그인·회원등록이 안 되어 있으면
                                      그 화면으로 보냈다가 **다시 돌아옵니다**
```

접수 기간 밖이면 신청 폼이 열리지 않고 **"접수 예정" / "접수 마감"** 만 보입니다.

### 알림마당 — 하위 3개

| 하위 메뉴 | 상태 |
|---|---|
| **공지사항** | ✅ 동작 — 담당자가 올린 공지가 보입니다 |
| 서식 자료실 | ⏸ 빈 화면 (공고문·서식 배포 예정) |
| FAQ · 문의 | 내용 채워짐 · **문의처 연락처는 아직 비어 있음** |

## 2. 회원(신청자)이 쓰는 곳 — **전부 마이페이지 안**

로그인하면 헤더 오른쪽에 **[마이페이지]** 가 생깁니다. **신청자가 하는 일은
사실상 전부 여기 모여 있습니다.**

```
마이페이지
 ├ 내 신청 현황        신청한 공고와 상태
 │   ├ 제출한 신청서(PDF) · 첨부 파일 열기
 │   ├ 담당자 안내       ← 보완 요청·미선정 사유가 여기 뜹니다
 │   └ 📌 정산          ← 선정된 건에만 나타납니다 (아래 참고)
 └ 내 정보             학번 · 전공 · 학년 · 이메일 · 연락처
```

### 📌 정산이 여기 있습니다 — 별도 메뉴가 아닙니다

**정산은 상단 메뉴에 없습니다.** 마이페이지의 **신청 카드 안**, 그 신청건이
**선정(approved)** 되었을 때만 나타납니다.

```
마이페이지 → 내 신청 현황 → [선정된 신청 카드] → 그 안의 [정산] 영역
                                                   ├ 지급 계좌 (은행·계좌번호·예금주)
                                                   └ 영수증 첨부 (선택)
```

**왜 여기 두었나**

- 정산은 **"어느 프로그램에 대한 정산인지"** 가 항상 붙어 다닙니다. 신청 카드
  안에 두면 그 연결이 화면에 그대로 보입니다
- 선정되지 않은 사람에게는 **아예 안 보입니다.** 별도 메뉴로 빼면 "눌렀는데
  아무것도 없다"가 됩니다
- 아직 지급 대상이 아닌 사람의 **계좌를 미리 받지 않게** 됩니다

**💬 의논해 볼 점** — 정산 기간이 되면 참여자에게 *"어디로 들어가야 하나요"*
문의가 올 수 있습니다. 상단에 **[정산]** 메뉴를 만들어 마이페이지로 보내는
방법, 정산 기간에만 안내 띠를 띄우는 방법 등이 있습니다.

### 계정 관련 화면 (메뉴에는 없고 필요할 때 나타납니다)

| 화면 | 어떻게 도달하나 |
|---|---|
| 로그인 | 헤더 [로그인] |
| 회원가입 | 헤더 [회원가입] |
| 회원 등록(추가 정보) | 가입 직후 자동 / 미완료 상태로 신청 시도할 때 |
| 비밀번호 재설정 | 로그인 화면의 "비밀번호를 잊으셨나요" |

## 3. 담당자가 쓰는 곳 — **[담당자] → 신청 관리에서 뻗어 나갑니다**

담당자 권한이 있는 계정에만 헤더에 **[담당자]** 가 보입니다. 누르면
**신청 관리** 화면으로 갑니다. **네 가지 일이 모두 여기서 시작됩니다.**

```
[담당자] → 신청 관리                      ← 여기가 담당자의 첫 화면
              │
              ├ (이 화면에서 직접) 신청 목록 · 상태 변경 · 사유 입력 · 신청 취소
              │
              ├ [프로그램 관리 →]   공고 등록 · 수정 · 공개/비공개
              ├ [공지 관리 →]       공지 작성 · 수정 · 삭제 · 고정
              └ [정산 관리 →]       계좌 확인 · 영수증 확인 · 승인/반려
```

즉 **모든 관리 기능이 "신청 관리" 화면 위쪽 버튼에 나란히** 있습니다.

### 3-1. 신청 관리 (담당자 첫 화면)

- 프로그램별 · 상태별로 걸러 보기
- 신청자 정보(제출 시점 사본), 첨부 파일·신청서 PDF 열기
- **상태 변경** — 제출 완료 / 검토 중 / 보완 요청 / 선정 / 미선정
- **사유 입력** — 여기 쓴 문장이 **신청자 마이페이지에 그대로** 보입니다
- **신청 취소 처리** — 기록은 남기고 그 사람이 다시 신청할 수 있게 풀어줍니다
- 구글 시트 반영 상태 표시 (실패 시 재시도 버튼)

### 3-2. 프로그램 관리 — **공고를 올리는 곳**

```
[담당자] → 신청 관리 → [프로그램 관리]
```

- 공고 등록 · 수정
- **공개 / 비공개 전환** (새 공고는 항상 비공개로 저장됩니다)
- 신청서에 붙일 **자유 기재란**과 **첨부칸**을 여기서 정합니다
- **삭제는 없습니다** — 신청 기록이 갈 곳을 잃기 때문입니다. 비공개로 내립니다

> 사용법: `docs/13-program-register-guide.md`

### 3-3. 공지 관리 — **공지를 올리는 곳**

```
[담당자] → 신청 관리 → [공지 관리]
```

- 공지 작성 · 수정 · 삭제
- **목록 맨 위 고정** (모집 공고처럼 계속 보여야 하는 것)
- 여기서 쓴 글이 **알림마당 → 공지사항**에 그대로 올라갑니다

### 3-4. 정산 관리

```
[담당자] → 신청 관리 → [정산 관리]
```

- 제출된 정산 목록 (상태별로 걸러 보기)
- **지급 계좌 — 기본은 가려져 있고 [보기]를 눌러야** 나옵니다
- 영수증 열어보기 (**금액은 파일을 열어 직접 확인**합니다).
  영수증은 선택이라 **없는 것이 정상일 수 있습니다** — 필요한 회차인데 안 왔다면
  사유를 적어 반려하세요
- **승인 / 반려** — 반려하려면 사유를 반드시 적어야 합니다

**💬 의논해 볼 점** — 담당자 화면 넷이 모두 "신청 관리"에서 뻗어 나갑니다.
공고를 올리러 들어갈 때도 **신청 목록을 먼저 지나야** 합니다. 담당자 첫
화면을 **[담당자 홈]** 같은 갈림길 화면으로 두고 네 가지를 나란히 놓는 방법도
있습니다. 지금은 화면이 넷뿐이라 그대로 두었습니다.

## 4. 사이트 밖에서 이루어지는 것

| 무엇 | 어디서 | 왜 사이트가 아닌가 |
|---|---|---|
| **신청 현황 집계·정렬** | 구글 스프레드시트 | 담당자가 익숙한 도구. 사이트에 통계 화면을 만들지 않기로 함 |
| **신청서 PDF 보관** | 공유 드라이브 `01_신청` | 시트에서 링크로 바로 열람 |
| **통장 사본** | — | **아예 받지 않기로 확인** (09-06) |
| **신분증** | — | **아예 받지 않기로 확인** (09-06) |

> ⚠️ **시트에서 상태를 고쳐도 사이트에는 반영되지 않습니다.**
> 상태의 원본은 사이트입니다. 시트는 사본입니다.
>
> ⚠️ **지급 계좌는 시트·드라이브로 나가지 않습니다.** 사이트 안에서만 봅니다.
>
> ✅ **사이트는 민감 서류(신분증·통장 사본)를 하나도 받지 않습니다.**
> 사이트가 가진 개인정보는 **가입 정보 + 지급 계좌 + 영수증**이 전부입니다.

## 5. 지금 비어 있는 화면 (메뉴는 있는데 내용이 없는 곳)

**메뉴를 눌렀는데 빈 화면이면 이용자는 고장으로 받아들입니다.** 접수 개시
전에 채우거나, 메뉴에서 잠시 내리는 판단이 필요합니다.

| 어디 | 상태 | 필요한 것 |
|---|---|---|
| **갤러리** | 화면만 있음 | 공개 방침(Q-15·G-a)과 **초기 콘텐츠**(Q-12) |
| **알림마당 → 서식 자료실** | 빈 화면 | 올릴 서식 파일 · 업로드 기능 |
| **알림마당 → FAQ 문의처** | 연락처 비어 있음 | **이메일·전화번호** |
| 사업소개 | 임시 명칭 | **사업 정식 명칭** |

## 6. 함께 정하면 좋을 것들 (의논용)

이 문서를 보시면서 **"여기 말고 저기"** 가 떠오르면 표시해 주세요.

- [ ] **정산을 상단 메뉴로 뺄지** — 지금은 마이페이지 안 (§2)
- [ ] **담당자 첫 화면을 갈림길로 만들지** — 지금은 신청 목록 (§3)
- [ ] **갤러리를 1차 오픈에 넣을지** — 내용이 없으면 메뉴에서 잠시 빼는 것도 방법
- [ ] **서식 자료실을 쓸지** — 신청서는 웹에서 쓰므로 배포할 서식이 실제로
      있는지 확인이 필요합니다
- [ ] 신청 상태 이름이 적절한지 — *제출 완료 / 검토 중 / 보완 요청 / 선정 /
      미선정 / 취소됨*. 재단·학교에서 쓰는 표현과 다르면 맞추는 게 낫습니다
- [ ] **미선정 사유를 신청자에게 보여줄지** (Q-13) — 지금은 담당자가 적으면
      그대로 보입니다. 안 적으면 안 보입니다
