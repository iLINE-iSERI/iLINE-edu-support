# 운영 매뉴얼 — 관리자가 알아야 할 것

> **사이트를 운영하면서 실제로 하게 되는 일**을 순서대로 적었습니다.
> 화면 설명은 `02-화면-지도.md`, 공고 등록 절차는 `01-공고-등록-안내서.md`.
> 이 문서는 **"언제 무엇을 하고, 어디서 사고가 나는가"** 를 다룹니다.
>
> 운영 주소: **`aiedu.iline.or.kr`** · 기준일: 2026-09-08

---

## ⚠️ 먼저 — 모르면 사고 나는 것 6가지

운영 중에 가장 자주, 그리고 가장 조용히 문제가 되는 지점들입니다.
**나머지를 다 잊더라도 이 여섯 개는 기억하세요.**

### 1. 담당자가 쓴 사유는 **신청자에게 보이지 않습니다** (D-46)

상태를 바꾸며 적는 「사유 · 처리 메모」는 **담당자만 봅니다.**

- **선정 결과** → **공지사항에 선정자 목록**을 올려 알립니다
- **보완 요청 · 정산 반려** → **메일·전화·카카오톡으로 직접** 알려야 합니다

> 🔴 **안 알리면 신청자는 같은 내용으로 다시 제출합니다.** 화면에는
> "반려"라는 상태만 뜨고 이유가 없기 때문입니다. 반려를 눌렀으면
> **연락도 함께** 하는 것을 습관으로 만드세요.

### 2. 구글 시트에서 상태를 고쳐도 **사이트에는 반영되지 않습니다**

상태의 **원본은 사이트**입니다. 시트는 담당자 편의를 위한 **사본**입니다.
시트에서 "선정"이라고 고쳐도 신청자 화면은 바뀌지 않습니다.
**상태 변경은 반드시 사이트에서** 하세요.

### 3. 초상권 동의는 **사람이 아니라 신청 건마다** 다릅니다 (D-44)

같은 사람이 A 프로그램은 동의하고 B 프로그램은 거부할 수 있습니다.
사진을 자료집·홈페이지에 쓸 때는 **"이 사람이 동의했나"가 아니라
"그 사진이 나온 프로그램의 신청 건이 동의했나"** 를 봐야 합니다.

> 시트에서 한 사람 이름이 여러 줄일 때 **줄마다 초상권 열의 값이 다를 수
> 있습니다.** 이름으로 찾지 말고 **프로그램 + 이름**으로 찾으세요.

### 4. 프로그램은 **삭제할 수 없습니다** — 비공개로 내립니다

지우면 그 프로그램에 낸 신청 기록이 갈 곳을 잃습니다.
잘못 만들었거나 접수를 닫고 싶으면 **[공개] 를 끄면** 됩니다.

### 5. 신청을 **취소 처리하면 그 사람이 다시 신청할 수 있게 됩니다**

취소는 기록을 지우지 않고 상태만 `취소됨`으로 남깁니다. 동시에
**중복 신청 잠금이 풀립니다.** 되돌리기 어려운 처리이므로,
"검토 중"을 고르는 것과 같은 무게로 누르지 마세요.

### 6. 담당자 권한을 회수할 때는 **세 곳을 모두** 해야 합니다

| 어디 | 안 하면 |
|---|---|
| ① Firestore `role` | 사이트 담당자 화면이 계속 열립니다 |
| ② Custom Claims `supportStaff` | 남의 첨부 파일을 계속 열 수 있습니다 |
| ③ **구글 시트·공유 드라이브 공유 해제** | **사이트에서 막아도 시트로 개인정보가 계속 보입니다** |

절차는 `03-담당자-권한-부여.md`.

## 1. 접수를 시작할 때

### 1-1. 공고 등록

`[담당자] → 신청 관리 → [프로그램 관리]` → 등록.
자세한 절차는 **`01-공고-등록-안내서.md`**.

준비해야 하는 것:

- 프로그램 이름 · 사업 연도
- **접수 시작·마감 일시** (분 단위까지)
- 안내 내용 — 모집 대상·인원·지원 내용
- **자유 기재란**이 필요한지, 필요하면 **그 칸의 이름** (예: `지원 동기`)
- **첨부 서류**를 받는지, 받으면 무엇을 내라고 안내할지

> **새 공고는 항상 비공개로 저장됩니다.** 미리보기 기능이 없어서, 저장 →
> 확인 → 공개 순서로 가도록 일부러 그렇게 했습니다. **공개를 켜야 신청자에게
> 보입니다.**

### 1-2. 접수 기간은 시스템이 강제합니다

시작 전에는 신청 폼이 열리지 않고, 마감 후에는 **제출 자체가 거부**됩니다.
담당자가 깜빡하고 늦게 닫아도 마감 시각은 지켜집니다.
반대로 **날짜를 잘못 넣으면 아무도 신청할 수 없습니다** — 등록 후
접수 시작일에 한 번 들어가 폼이 열리는지 확인하세요.

### 1-3. 공지 올리기

`[담당자] → 신청 관리 → [공지 관리]`.
모집 공고처럼 계속 보여야 하는 글은 **[목록 맨 위 고정]** 을 켜세요.

## 2. 신청을 심사할 때

### 2-1. 어디서 보나

`[담당자] → 신청 관리`. 프로그램별·상태별로 걸러 볼 수 있고,
신청서 PDF와 첨부 파일을 여기서 바로 엽니다.

집계·정렬은 **구글 스프레드시트**에서 하세요. 사이트에 통계 화면을 만들지
않기로 한 이유가 이것입니다 — 담당자가 익숙한 도구를 쓰는 편이 낫습니다.

### 2-2. 상태 바꾸기

**제출 완료 → 검토 중 → 보완 요청 / 선정 / 미선정**

사유 칸에 적은 내용은 **담당자 기록용**입니다(위 ⚠️1 참고).
나중에 "왜 그렇게 판단했더라"를 확인할 근거가 되니 **적어두는 편이
좋습니다.** 다만 신청자에게 전달되지는 않습니다.

### 2-3. 결과 알리기 — 공지사항에 선정자 목록

```
[담당자] → 공지 관리 → 새 공지
   제목: 2026 ○○ 프로그램 선정자 안내
   내용: 선정자 명단 + 다음 일정 안내
```

> 🔴 **공지사항은 로그인 없이 누구나 봅니다.** 선정자 명단을 올리는 것은
> **개인정보 공개**입니다. 무엇을 적을지(이름만 / 이름 + 학번 뒤 4자리)를
> 미리 정하고, **개인정보처리방침의 이용 목적에 "선정 결과 공고"** 가
> 들어 있는지 확인하세요.
>
> 동명이인이 있으면 이름만으로는 본인 확인이 안 됩니다.

### 2-4. 신청 취소

신청자가 요청했거나 착오로 낸 건은 `[신청 취소 처리]`.
기록은 `취소됨`으로 남고 **그 사람이 다시 신청할 수 있게 됩니다**(⚠️5).

## 3. 정산할 때

### 3-1. 신청자 쪽 — 마이페이지 안에 있습니다

정산은 **상단 메뉴에 없습니다.** 마이페이지의 **선정된 신청 카드 안**에만
나타납니다. 참여자가 *"어디로 들어가나요"* 라고 물으면 이렇게 안내하세요:

> 마이페이지 → 내 신청 현황 → 선정된 프로그램 카드 → 그 안의 [정산]

### 3-2. 담당자 쪽

`[담당자] → 신청 관리 → [정산 관리]`.

- **지급 계좌는 기본으로 가려져 있습니다.** `[보기]` 를 눌러야 나옵니다 —
  목록을 띄워둔 채 자리를 비우거나 화면을 공유할 때를 대비한 것입니다
- **금액 칸이 없습니다.** 영수증을 열어 직접 읽고 합산하세요
- **영수증은 선택입니다.** 없는 것이 정상일 수 있습니다. 증빙이 필요한
  회차인데 안 왔다면 사유를 적어 반려하세요

### 3-3. 계좌는 사이트 밖으로 나가지 않습니다

은행명·계좌번호·예금주는 **구글 시트·드라이브로 내보내지 않습니다.**
지급하려면 이 화면에서 봐야 합니다. 지급이 끝나면 보유기간에 따라
파기합니다.

### 3-4. 반려할 때는 연락도 함께

사유가 신청자에게 안 보이므로(⚠️1), **무엇을 고쳐야 하는지 메일·전화로
알려야** 합니다. 안 알리면 같은 내용으로 다시 옵니다.

## 4. 구글 시트·드라이브

### 무엇이 자동으로 들어가나

| 어디 | 무엇 | 언제 |
|---|---|---|
| 스프레드시트 | 신청 1건 = 1줄 (15열) | 제출 즉시 |
| 공유 드라이브 `01_신청` | 신청서 PDF | 제출 즉시 |

반출 범위는 `docs/4-기록/02-시트-드라이브-반출-범위.md` 에서 확정했습니다.
**여기 없는 항목은 내보내지 않습니다.**

### 안 들어갔을 때

담당자 화면의 해당 신청 카드에 **「구글 시트 반영 실패」** 와 사유가 뜨고
**[다시 시도]** 버튼이 있습니다. **신청 자체는 이미 정상 접수된 상태**이니
당황하지 마세요 — 시트는 사본입니다.

### 공유 멤버 점검

학기마다 또는 담당자가 바뀔 때 **공유 드라이브 멤버 목록**을 확인하세요.
사이트 권한만 회수하고 시트 공유를 안 풀면 개인정보가 계속 보입니다(⚠️6).

> 열립니다.** 사이트 안에서 되는 일은 사이트에서 하세요.

## 6. 이용자가 물어볼 만한 것

| 질문 | 답 |
|---|---|
| "회원가입이 안 돼요" | 2단계(참여 정보)까지 마쳐야 가입이 끝납니다. 1단계만 하고 나가면 계정이 만들어지지 않습니다 |
| "신청 버튼이 없어요" | 접수 기간이 아니거나, 이미 신청한 프로그램입니다 |
| "이미 신청했는데 다시 내고 싶어요" | 담당자가 **신청 취소 처리**를 해줘야 다시 열립니다 |
| "결과는 어디서 봐요" | **공지사항**의 선정자 목록. 마이페이지에서도 상태를 볼 수 있습니다 |
| "정산은 어디서 해요" | 마이페이지 → 선정된 신청 카드 안 |
| "학년이 바뀌었어요" | **회원정보 수정 화면이 아직 없습니다.** 담당자에게 문의하도록 안내 |
| "탈퇴하면 낸 서류도 지워지나요" | 국고사업 보존 의무가 있어 신청·정산 이력은 남습니다 |

> 그리고 **push 하지 않으면 배포본은 옛 코드 그대로**입니다.
